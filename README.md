# Cosima Heilmaier — website concept

A static, German-language proof of concept for a personal website for pianist and bassoonist Cosima Heilmaier. This is an informal design proposal, not her official website. Contact details and media are intentionally not invented.

Open `index.html` in a browser, or run `python3 -m http.server 8000` from the repository root and visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create an empty GitHub repository and push this project to its `main` branch. The repository name can be anything; it determines the URL path.
2. In the GitHub repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)` and click **Save**.
4. Wait for GitHub's deployment to finish. The site will be at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

There is no build step or dependency installation. Keep `index.html`, `styles.css`, `script.js`, and `assets/` together at the repository root. A repository named `YOUR-USERNAME.github.io` instead gets the shorter `https://YOUR-USERNAME.github.io/` URL, but renaming is not required.
